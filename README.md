# Calculadora de Consumo y Propina

Esta aplicación web se trata de un cotizador de consumo mediante la selección de productos a consumir en una orden y la deducción y cálculo del consumo y propina de la misma.

Utilicé React + Typescript + Tailwind para su desarrollo, implemente Componentes reutilizables y un Custom Hook para optimizar la reutilización y agrupamiento de código. Aprendí sobre la utilización de react hooks como useMemo, useCallback, useState.

Se resuelve el inconveniente del cálculo eficiente y automatizado para consumo en mesa, permitiendo la selección de porcentaje de propina a abonar.

Este código fue implementado con el gestor de paquetes PNPM debido al inconveniente de NPM por ciber ataque.

### Instala dependencias utilizando:

```javascript
pnpm install
```

### Utiliza para correr este proyecto:

```javascript
pnpm run dev
```
